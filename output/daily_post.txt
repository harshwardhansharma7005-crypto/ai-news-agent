🤖 New AI models from Meta, Microsoft, and Reflection advance coding and agent capabilities
📅 16 Oct 2026 | Daily AI News Roundup

1. Scale Agentic Coding Workflows with Meta’s Muse Spark Open on NVIDIA GB300 NVL72
Meta launched Muse Spark Open, an 816B mixture-of-experts model optimized for agentic coding workflows, with a 1M token context window. Trained on NVIDIA GB300 NVL72, it offers higher accuracy, reliable tool calling, and deep codebase understanding.
🔗 Source: NVIDIA Developer Blog - https://developer.nvidia.com/blog/scale-agentic-coding-workflows-with-metas-muse-spark-open-on-nvidia-gb300-nvl72/

2. What’s new in Microsoft Foundry | September 2026
Microsoft Foundry released September 2026 updates, including GPT-6.1 Sol, Routines, and Tool Search GA, expanding its AI model lineup and agent capabilities. This matters for developers using Microsoft's AI platform.
🔗 Source: Microsoft Foundry Blog - https://devblogs.microsoft.com/foundry/whats-new-in-microsoft-foundry-september-2026/

3. Welcome Beam: a 501B open model you can own, customize, and scale
Reflection launched Beam, a 501B parameter open mixture-of-experts model with a 1M token context window, focused on coding and agentic use cases. This provides a frontier-scale, customizable model for teams to own and scale.
🔗 Source: Hugging Face Blog - https://huggingface.co/blog/reflection-beam

4. NVIDIA Nemotron 3.5 Super VL Powers Specialized Agents with Multimodal Reasoning
NVIDIA launched Nemotron 3.5 Super VL, an open, customizable 120B-parameter multimodal model for specialized agent workflows. It combines reasoning, instruction following, and tool use with text, image, document, and video understanding, offering higher throughput for agentic tasks.
🔗 Source: NVIDIA Developer Blog - https://developer.nvidia.com/blog/nvidia-nemotron-3-5-super-vl-powers-specialized-agents-with-multimodal-reasoning/

5. Meta launches an open-weight AI model that runs on Macs
Meta launched Muse Spark Open, an open-weight AI model designed to run locally on Apple Macs, leveraging 816 billion parameters and a 1 million token context window. This marks a collaboration between Meta and Apple to bring powerful AI capabilities to desktop users.
🔗 Source: TechCrunch AI - https://techcrunch.com/2026/10/15/meta-launches-an-open-weight-model-that-runs-on-macs/

6. Scaling Indic Pretraining: 2.8 Trillion Tokens and an Open Data Generation Pipeline
NVIDIA, with IIT Madras, is releasing Nemotron-pretraining-Indic-v1, a 2.8 trillion token corpus for 22 Indian languages, along with an open, GPU-accelerated data generation pipeline. This advances AI capabilities for Indic languages.
🔗 Source: Hugging Face Blog - https://huggingface.co/blog/nvidia/scaling-indic-pretraining

7. How Meta Built Forum With AI-Native Engineering
Meta built its new app, Forum, using an AI-native engineering approach where an AI agent participates in the engineering process. This new methodology focuses on verified, production-ready outcomes across planning, building, testing, and verification.

Google introduced Antigravity, an agentic science workbench that accelerates the discovery and evaluation of antimicrobial peptides. This platform helps biologists quickly find and prioritize novel therapeutic candidates, compressing a previously labor-intensive process.
